# GiftGraph: Vercel и закрытый Blob

Сайт: https://giftgraph-miniapp.vercel.app/
Проект: giftgraph-miniapp, команда: deruko77-3626.

Сайт, Mini App и сохраненные графы работают без ПК. На ПК остаются бот,
Telethon, база пользователей и построение новых графов. Туннель не нужен.

## Запуск бота

```powershell
cd "C:\Users\admin\Documents\Vibe Code Projects\tg"
.\tg_gift_bot\manage.ps1 start
```

Для остановки используйте `stop`, перезапуска — `restart`, состояния — `status`,
журнала — `logs`. Не запускайте параллельно вторую копию через `python main.py`.
Боту нужен рабочий доступ к Telegram и Vercel через сеть ПК.

Оба адреса в настройках бота теперь облачные:

```env
GIFTGRAPH_WEB_URL=https://giftgraph-miniapp.vercel.app
GIFTGRAPH_WEB_API_URL=https://giftgraph-miniapp.vercel.app
```

Существующий секрет загрузки сохранен и настроен в Production Vercel.
Не публикуйте секреты. В личном чате команда `/app` и меню GiftGraph открывают
Mini App; `/search @username` строит и загружает новый граф.

## Публикация изменений сайта

```powershell
cd "C:\Users\admin\Documents\Vibe Code Projects\tg"
.\giftgraph-web\publish.ps1
```

Это публикация новой версии, а не ежедневный запуск. Скрипт копирует только
код приложения и публичные assets в связанную папку `vercel` и публикует сайт.
Секреты, база и Telegram-сессия бота не попадают в деплой.

## Хранение и проверка

Закрытый Blob: giftgraph-graphs, store_wt1ykwGAlAAdNPyW, регион iad1.
Каждый граф хранится отдельно: HTML в `graphs/<id>.html`, метаданные в
`metadata/<id>.json`. Метаданные публикуются после HTML. Общий индекс не
перезаписывается, поэтому независимые загрузки не теряют чужие записи.

Проверено 2026-10-07: перенесены 13 графов с прежними ID; HTML и метаданные
сверены. Публичные загрузка, просмотр и удаление проверены на временном графе.
Запрос на загрузку без секрета отклоняется. Локальный сервер и туннель остановлены;
публичный `/health` возвращает 200 и `storage: "blob"`.

Локальные `graphs` сохранены как резервная копия прежнего архива. Новые облачные
графы автоматически в эту папку не скачиваются. Лимиты Vercel Blob Hobby
можно проверить в панели Vercel. Максимальный JSON-запрос — 4 MiB;
самый большой граф текущего архива меньше 0.5 MB.

## Повторный перенос и возврат к прежней схеме

`migrate_archive.py` читает игнорируемый файл `vercel/.env.production.local`,
копирует локальные графы с прежними ID и проверяет содержимое. Повторный запуск
принимает совпадающие графы и отказывается перезаписывать другое содержимое.
Облачные проверки: `python -m unittest test_cloud.py` из папки giftgraph-web.

Прежний посредник сохранен в `vercel/gateway_server.py` и исключен из деплоя.
Для возврата сначала сохраните новые облачные графы, затем запустите локальный
сервер и туннель, верните посредник в `vercel/server.py`, разверните с актуальным
GIFTGRAPH_BACKEND_URL и измените адрес загрузки бота на http://127.0.0.1:5100.
Простой откат к старому деплою недостаточен: его временный туннель мог истечь.
Хранилище Blob и исходный архив при возврате не удаляйте.
